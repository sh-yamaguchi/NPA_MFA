# NPA-charge-field analysis

This repository contains the scripts, aligned transition-state (TS) structures, target values, and compiled library required to reproduce the NPA-charge-field analysis described in the manuscript:

**“Transition-State Steric Fields Capture Geometric Signatures Associated with Electronic Perturbations in Asymmetric Catalysis.”**

The analysis was performed for the major and minor TS pathways of three asymmetric Michael addition systems:

- R1major
- R1minor
- R2major
- R2minor
- R3major
- R3minor

## Terminology note

The atomic charges used in this repository are **natural population analysis (NPA) charges obtained from NBO analysis**. For compatibility with the original implementation, some internal filenames, class names, comments, and library names retain the designation `nbo` or `NBO` (for example, `nbo_descriptor.py`, `NBOFieldAnalysis`, and `nbo_field.so`). These names refer to the implementation and do not change the fact that the mapped atomic charges are NPA charges.

## Requirements

The analysis requires:

- Python 3
- NumPy
- R
- R package `glmnet`

The code was tested under **macOS 12 on Apple Silicon (arm64)** with **Python 3.12**.

The compiled library `lib/nbo_field.so` included in this repository is a macOS arm64 binary. Source code for this compiled library is not included in the repository.

The descriptor matrices, regression results, and visualization files are **not included in this GitHub repository**; they are generated by the workflow below. The corresponding result files used in the manuscript are provided separately in the Supporting Information.

## 1. Generation of NPA-charge-field descriptors

Run the following command from the `NPA_MFA` directory:

```bash
python3 nbo_descriptor.py
```

The script generates NPA-charge-field descriptors for all six datasets.

For each aligned TS structure, an **8 × 8 × 8 Å³** grid with a voxel size of **1 Å per side** is used. Voxels assigned to atoms are given the NPA charge of the nearest atom, whereas unassigned voxels are given a value of zero.

The molecular structures included in each dataset are specified by the corresponding `mol_name_*.txt` file. For example:

```text
mol_name_R1major.txt
        ↓
nbo_descriptor.py
        ↓
descriptorR1major.txt
```

The generated descriptor files are:

```text
descriptorR1major.txt
descriptorR1minor.txt
descriptorR2major.txt
descriptorR2minor.txt
descriptorR3major.txt
descriptorR3minor.txt
```

## 2. LASSO regression

After generating the descriptor files, run:

```bash
Rscript regression.R
```

The script performs LASSO regression for all six datasets using the functions in `lib/mfa.R`.

The target-variable files are:

```text
targetR1.txt
targetR2.txt
targetR3.txt
```

The same target-variable file is used for the major and minor pathways of each reaction because the target value is the calculated free-energy difference between the two pathways (ΔΔG‡).

The LASSO parameter is set to `alpha = 1.0`, and the optional limit on the number of selected descriptors (`pmax`) is turned off.

For each dataset, the regression analysis generates two principal output files. For example, for R1major:

```text
R1major_output.csv
coefficient_R1major.txt
```

Corresponding files are generated for the other five datasets.

The `*_output.csv` files contain the target values, fitted values, and leave-one-out cross-validation (LOOCV) predictions (`measured`, `pred`, and `pred_LOOCV`, respectively).

The `coefficient_*.txt` files contain the regression coefficients assigned to the voxel descriptors. These files are subsequently read by `nbo_visualization.py` to generate the three-dimensional visualization data.

## 3. Visualization of NPA-charge fields

After the regression step, run:

```bash
python3 nbo_visualization.py
```

The script reads the regression-coefficient files together with the corresponding molecular-structure lists and generates visualization data for all six regression models:

```text
visR1major/
visR1minor/
visR2major/
visR2minor/
visR3major/
visR3minor/
```

Only voxels with an absolute regression coefficient of at least **0.01** are used for visualization. Voxels with an assigned NPA charge of zero are excluded.

For each TS structure, two types of visualization files are generated:

```text
*_overlay.xyz
*_overlay_voxels.tsv
```

The `*_overlay.xyz` files contain the TS structures together with pseudoatoms indicating the selected voxel positions for three-dimensional visualization. The corresponding `*_overlay_voxels.tsv` files contain the numerical voxel-level information used to construct these visualizations.

## 4. Interpretation of the visualization files

### `*_overlay.xyz`

The `*_overlay.xyz` file contains the original TS structure together with pseudoatoms placed at the centers of voxels selected by the regression model.

The pseudoatoms are visualization markers only and do not represent real He, Ne, Ar, or Kr atoms.

The four pseudoatom types distinguish the sign of the assigned NPA charge and the sign of the regression coefficient:

| Category | Pseudoatom | NPA charge | Regression coefficient |
|---|---|---|---|
| qPP | He | positive | positive |
| qPN | Ne | positive | negative |
| qNP | Ar | negative | positive |
| qNN | Kr | negative | negative |

The pseudoatoms can therefore be displayed and recolored in a molecular visualization program to reproduce the spatial NPA-charge-field visualizations used in the analysis.

The comment line at the beginning of each `*_overlay.xyz` file also provides summary information for that structure, including the predicted target value and the number of voxels retained for visualization.

### `*_overlay_voxels.tsv`

The corresponding `*_overlay_voxels.tsv` file provides the numerical information for each displayed voxel.

The columns are:

- `cat`: category of the voxel (`qPP`, `qPN`, `qNP`, or `qNN`)
- `x`, `y`, `z`: Cartesian coordinates of the voxel center
- `coef`: regression coefficient assigned to the voxel
- `q_assigned`: NPA charge assigned to the voxel
- `owner_atom_index`: index of the nearest atom from which the NPA charge was assigned
- `owner_element`: element of the nearest atom

These files provide the numerical data underlying the three-dimensional NPA-charge-field visualizations and allow the relationship between each displayed voxel, its regression coefficient, and its assigned atomic charge to be inspected directly.

## 5. Reproducing the analysis

The complete workflow is:

```text
Aligned TS structures with NPA charges
        ↓
nbo_descriptor.py
        ↓
NPA-charge-field descriptors
        ↓
regression.R
        ↓
Regression coefficients and predictions
        ↓
nbo_visualization.py
        ↓
3D visualization files
```

The three steps should be run in the order shown above. The first step generates the descriptor matrices required by `regression.R`, and the regression step generates the coefficient files required by `nbo_visualization.py`.

For details of the construction of the molecular fields, regression conditions, and interpretation of the results, see the Supporting Information accompanying the manuscript.
